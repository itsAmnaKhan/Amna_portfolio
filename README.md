# Amna's Portfolio

This repository contains the source for my personal portfolio website. It
introduces my work as a biomedical engineer and presents my publications,
research journey, selected projects, highlights and contact details.

The site is a single static HTML file with inline CSS and vanilla JavaScript.
Its interactive features include project filters, case-study pop-ups with image
galleries, a lightbox and an animated cover based on the printed portfolio. The page is in
[index.html](index.html), with local visual assets stored in `Images/`.
